# Calculations BREAD Application
**NAME: Jianna Aguilar
**COURSE ID: IS218-450
This application implements full BREAD (Browse, Read, Edit, Add, Delete) operations for user calculations using **FastAPI**, **SQLAlchemy**, **SQLite**, and a dynamic HTML/JavaScript frontend. End-to-end (E2E) testing is managed with **Playwright**, and automated integration/deployment is handled via **GitHub Actions** and **Docker Hub**.
